Chave permanente do APK Android (Pacto Talk)

Abra este arquivo direto do seu computador (funciona sem internet). A chave é criada aqui, pelo navegador, e não vai para nenhum servidor. Faça isto uma vez só: todo APK futuro precisa ser assinado com esta mesma chave, senão o Android recusa a atualização.

Gerando…

1. Guarde a cópia de segurança AGORA

Sem esta cópia, se o segredo do GitHub sumir, ninguém consegue mais atualizar o app (teria que instalar outro e passar todo mundo de novo).

Guarde o arquivo num pendrive que fica guardado e no seu gerenciador de senhas. Depois apague da pasta Downloads. Não mande por e-mail nem mensagem.

2. Segredo ANDROID_SIGNING_KEY

GitHub → Settings → Secrets and variables → Actions → New repository secret. Cole tudo. Não mostre a ninguém.

3. Segredo ANDROID_SIGNING_CERT

Certificado público (pode mostrar), também como segredo para o workflow.

4. Variável ANDROID_CERT_SHA256

Na aba Variables (não Secrets). É a impressão digital da chave: o workflow só publica se a chave bater com ela, e qualquer pessoa confere no APK.

Depois de copiar, feche esta aba.
