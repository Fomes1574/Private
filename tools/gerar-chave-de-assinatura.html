Chave de assinatura e códigos do Mensageiro

Abra este arquivo direto do seu computador (sem internet funciona). A chave é criada aqui mesmo, pelo navegador, e não vai para nenhum servidor.

1. Chave privada → segredo MP_RELEASE_KEY no GitHub

Copie tudo, inclusive as linhas BEGIN e END. Não mande para ninguém.

2. Chave pública (pode mostrar)

Anote. Ela aparece no log de cada publicação: se um dia vier outra, alguém trocou a chave.

Depois de colar no GitHub, feche esta aba. Guarde uma cópia da chave privada no seu gerenciador de senhas: sem ela, quem já instalou o app não aceita atualizações.

3. Códigos aleatórios para os outros segredos

Feitos pelo gerador aleatório do próprio navegador. Copie cada um para o segredo de mesmo nome no GitHub e guarde no gerenciador de senhas.

PROVA_TOKEN_SECRET (48 caracteres)

MP_SETUP_CODE (24 caracteres; você digita uma vez no iPhone)

PROVA_ACCESS_CODE (12 caracteres; você digita na Prova 5)
