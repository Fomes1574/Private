# Pacto Talk | Identidade visual

Nome exibido: **Pacto Talk**.

O ícone foi fornecido pelo proprietário e preparado em versões otimizadas para a tela inicial. Arquivo 180 px (PNG) para Apple Touch Icon e 512 px (WebP) para PWA e Android.

Identificadores técnicos como `com.mensageiro.privado`, nomes dos Workers e origem da PWA **não foram alterados**, para preservar atualização, dados locais, convites e chaves existentes.

Para atualizar a PWA, execute `deploy-app` após a alteração do código. O workflow `android` gera automaticamente um novo APK de teste. Não distribua APK de debug como versão final.
